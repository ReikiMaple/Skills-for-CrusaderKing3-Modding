The console

Crusader Kings III offers a debug mode **(disabled by default)** that allows the inputting of console commands. This page lists the codes that may be input into the Console Window, a special debugging window that may be accessed in non-ironman games while in debug mode by pressing Shift+2, ALT+2+1, Shift+3, `§`, `~`, `^`, `°`, `²`, or `` ` `` (key varies based upon keyboard layout). For QWERTY keyboards, the key is `` ` ``. Otherwise, Shift + Alt + C may work if the prior combinations did not. Press the up or down arrow keys to traverse through previously executed commands. Many codes can be turned off by repeating the command, but sometimes reloading the save or exiting the game is necessary.

Character IDs can be seen by hovering the cursor over a character with debug mode enabled.

## Debug mode\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=1 "Edit section: Debug mode") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=1 "Edit section: Debug mode")\]

Debug mode is a set of game tools that allow to modify game behavior outside of normal means. It includes:

- Console Window (accepts console commands)
- Debug Menus (including the Portrait Editor, GUI Editor, Tweak Menu and others)
- Debug Character Interactions (user can instantly change opinion, imprison and more)
- Ctrl + clicking on a portrait takes control of the character, while Alt + click kills them
- File watcher that automatically reloads changed files (including mods) into memory

### Enabling debug mode\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=2 "Edit section: Enabling debug mode") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=2 "Edit section: Enabling debug mode")\]

Debug mode can be enabled before launching the game and/or toggled in the game using mods. It can be disabled from the console, but can't be re-enabled after it's closed (unless with mods).

How to enable it:

#### Mods\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=3 "Edit section: Mods") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=3 "Edit section: Mods")\]

There are a number of mods, like [Free Console Access](https://steamcommunity.com/sharedfiles/filedetails/?id=2218150778) and [Debug Toggle](https://steamcommunity.com/sharedfiles/filedetails/?id=2264428428).

They allow to toggle the debug mode on and off, making it convenient to use the console and play, but this doesn't enable instant reloading of files. For modding, it's better to use both a mod and launch options.

#### Launcher\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=4 "Edit section: Launcher") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=4 "Edit section: Launcher")\]

In the game Launcher:

1. Switch to Game Settings on the left
2. Scroll down to "Open game in Debug Mode" section and click Launch

#### Steam\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=5 "Edit section: Steam") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=5 "Edit section: Steam")\]

On Steam:

1. Right-click the game, open Properties
2. Add `-debug_mode` to the Launch Options at the bottom
3. Start the game

#### Windows\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=6 "Edit section: Windows") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=6 "Edit section: Windows")\]

Without Steam, on Windows:

1. Go to your CK3 directory, "binaries" folder
2. Right-click ck3.exe and create a shortcut
3. Right-click the shortcut, open Properties
4. In the Target field add `-debug_mode` at the end (so it looks like this `"...\ck3.exe" -debug_mode`)
5. Launch the game using the shortcut

Alternatively

1. Go to your CK3 directory, "binaries" folder
2. Right click to create a new text file in Notepad
3. Add the following: `start ck3.exe -debug_mode`
4. Go to File and click Save As
5. Save As a batch file (.bat)
6. Launch the game using the batch file

#### GOG\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=7 "Edit section: GOG") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=7 "Edit section: GOG")\]

On GOG:

1. Right-click the game, open Settings
2. Check "Add command line arguments" and enter `debug_mode`

On GOG Galaxy 2.0:

1. In the game page, select Settings (next to the Play button at the top of the page)
2. Open Manage installation and select Configure...
3. Make sure the Launch parameters "Custom executables / arguments" is ticked at the bottom of the page. You can duplicate the "startgame" executable and type `-debug_mode` into the Arguments field.

#### Xbox Game Pass\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=8 "Edit section: Xbox Game Pass") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=8 "Edit section: Xbox Game Pass")\]

For the Xbox Game Pass / Windows 10 Store edtion it's more complicated, as you cannot create a normal shortcut for it, so you'll have to run the following commands in Command Prompt every time you open the game:

`start shell:AppsFolder\ParadoxInteractive.ProjectTitus_zfnrdv2de78ny!App -debug_mode`

To simplify it, you can also create a batch (.bat) file with this command and run it from the desktop:

1. Right-click on your Desktop, choose New -> Text Document.
2. Rename it to "ck3.bat". Make sure to remove ".txt" from the end. Confirm changes when prompted.
3. Right-click the file and select Edit.
4. Paste the command: `start shell:AppsFolder\ParadoxInteractive.ProjectTitus_zfnrdv2de78ny!App -debug_mode`
5. Save the file
6. Double-click it to start the game

### Disabling debug mode\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=9 "Edit section: Disabling debug mode") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=9 "Edit section: Disabling debug mode")\]

To activate achivements again, disable all active mods and remove -debug\_mode from launch options. After launching the game, make sure you have the [correct checksum](https://ck3.paradoxwikis.com/Patches "Patches"). It can be found in the right corner in the Main Menu.

## Debug info\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=10 "Edit section: Debug info") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=10 "Edit section: Debug info")\]

Debug info can be enabled and disabled either from one of the console buttons or by using the debug\_mode command. When debug info is activated, characters, interactions and events will show debug info which is normally hidden during normal gameplay. It should be noted that when debug info is enabled the game will consume a bit more resources but it shouldn't have a noticeable effect on most machines.

### Events\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=12 "Edit section: Events") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=12 "Edit section: Events")\]

Hovering over event options will show the AI weight for the option. Also, in the top-right corner of the event window, hovering over the question mark (`?`) shows internal details, including the following:

- [Event ID](https://ck3.paradoxwikis.com/index.php?title=Event_ID&action=edit&redlink=1 "Event ID (page does not exist)")
- Character for whom the event triggered
- Root character
- Saved event targets
- Saved list targets
- Descriptions

### Interactions\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=13 "Edit section: Interactions") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=13 "Edit section: Interactions")\]

In a given interaction's menu, hovering over the purple R next to the final button will show the root scope, the primary/secondary actors and the primary/secondary recipients.

### Converting commands\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=16 "Edit section: Converting commands") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=16 "Edit section: Converting commands")\]

The following commands can be used to convert the realm to a faith, culture or government.

| Command | Conversion |
| --- | --- |
| effect every\_held\_title = { set\_county\_culture = root.culture } | Converts every domain county to the character's culture |
| effect every\_sub\_realm\_county = { set\_county\_culture = root.culture } | Converts every realm county to the character's culture |
| effect every\_sub\_realm\_county = { set\_county\_faith = root.faith } | Converts every realm county to the character's faith |
| effect every\_vassal\_or\_below = { set\_culture = root.culture } | Converts every vassal and sub-vassal to the character's culture |
| effect every\_vassal\_or\_below = { set\_character\_faith = root.faith } | Converts every vassal and sub-vassal to the character's faith |
| effect every\_courtier\_or\_guest = { set\_culture = root.culture } | Converts every courtier and guest to the character's culture |
| effect every\_courtier\_or\_guest = { set\_character\_faith = root.faith } | Converts every courtier and guest to the character's faith |
| effect every\_courtier\_or\_guest = { set\_age = 20 } | Converts every courtier and guest to the age of 20 (can replace the number with a different value) |
| effect every\_vassal\_or\_below = { change\_government = feudal\_government } | Converts every vassal and sub-vassal to Feudal government (can replace the government ID with any other) |
| effect every\_sub\_realm\_county = { change\_development\_level = 100 } | Changes the development of every realm county to 100 (can replace the number with a different value) |

_Main article: [Traits](https://ck3.paradoxwikis.com/Traits "Traits")_

All traits have a tag that is referenced internally by the game. They can be found in `game\common\traits\00_traits.txt`. A trait's tag typically matches its name. To get a trait's tag from its name, perform the following steps:

- Replace spaces (``) and dashes (`-`) with underscores (`_`)
- Remove all apostrophes (`'`)
- Turn all upper case letters into lower case (`A...Z->a...z`)

## Title Tags\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=21 "Edit section: Title Tags") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=21 "Edit section: Title Tags")\]

_Main article: [Titles](https://ck3.paradoxwikis.com/Titles "Titles")_

All titles have an internal title tag that can be found in `game\common\landed_titles\00_landed_titles.txt`. Title tags have a prefix based on their rank, followed by an underscore (`_`) and then their name.

| Rank | Prefix | Example |
| --- | --- | --- |
| ![](https://ck3.paradoxwikis.com/images/thumb/2/20/Barony.png/24px-Barony.png) Barony | `b_` | `Wigmore -> b_wigmore` |
| ![](https://ck3.paradoxwikis.com/images/thumb/2/26/County.png/24px-County.png) County | `c_` | `Sundgau -> c_sundgau` |
| ![](https://ck3.paradoxwikis.com/images/thumb/5/5a/Duchy.png/24px-Duchy.png) Duchy | `d_` | `Sicily -> d_sicily` |
| ![](https://ck3.paradoxwikis.com/images/thumb/0/01/Kingdom.png/24px-Kingdom.png) Kingdom | `k_` | `Denmark -> k_denmark` |
| ![](https://ck3.paradoxwikis.com/images/thumb/9/9d/Empire.png/24px-Empire.png) Empire | `e_` | `Persia -> e_persia` |

### Finding title tags based on in-game name\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=22 "Edit section: Finding title tags based on in-game name") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=22 "Edit section: Finding title tags based on in-game name")\]

The title ID may not match the title's name in-game. For example, the player may have their game set to a language other than English or a title has a culture-specific name. Use the following steps to find a title ID purely on its in-game name:

- Navigate to the file located at `game\localization\LANGUAGE\titles_l_LANGUAGE.yml`, replacing `LANGUAGE` with your game language.
- Open the file with a text editor like Notepad++ and search for any instances of the in-game name using `CTRL` \+ `F`.
- If you managed to find a match:
  - The line should look similar to ` b_my_barony_name:0 "In-game name for barony"`.
  - The title ID is the word before the `:0`, therefore being `b_my_barony_name` in this example.
- If you could not find a match:
  - Close the file.
  - In the same folder as the previous file, open the file `titles_cultural_names_l_LANGUAGE.yml`, replacing `LANGUAGE` appropriately.
  - Repeat your search for the title's in-game name in this file.
  - When you find a match, it should look like so: ` cn_lunden:0 "Lunden"`.
  - Remember/copy the word before the `:0` (in this example, `cn_lunden`); this is a _cultural name key_ of the title.
  - Close the file.
  - Navigate to the file `game\common\landed_titles\00_landed_titles.txt` and open it with your text editor.
  - Perform a search for the _cultural name key_ you found in the previous file (e.g., `cn_lunden`).
  - The search query should land within a block named `cultural_names` enclosed by curly brackets (`{`, `}`).
  - Read the lines above until you reach another start of a block (denoted by `b_london = {`). Ignore any blocks like `color = {` or `color2 ={`.
  - The word in place of `b_london` is your title ID.

### Finding custom title tags\[ [edit](https://ck3.paradoxwikis.com/index.php?title=Console_commands&veaction=edit&section=23 "Edit section: Finding custom title tags") \| [edit source](https://ck3.paradoxwikis.com/index.php?title=Console_commands&action=edit&section=23 "Edit section: Finding custom title tags")\]

Custom titles (i.e. the title of a player created Empire) do not follow the same naming convention. To find the ID:

- From the debug console use the command `explorer` to open Object Browser
- In Object Browser choose Provider: Landed Titles
- Enter search term
- Hover over the Name field to show the title card
